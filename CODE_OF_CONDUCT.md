# Code of Conduct

This repository is for technical development.

- **Scope:** discussions, issues, and pull requests should focus on the
  `python-template` template, its tooling, and the projects it generates.
- **Conduct:** be direct about code and considerate about people. Critique the
  change, not the contributor.
- **Moderation:** off-topic, abusive, or bad-faith content will be closed or
  removed.

Report conduct concerns to the maintainers, or through GitHub's [report
content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature.
