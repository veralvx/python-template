# Code of Conduct

This repository is for technical development.

- **Scope:** discussions, issues, and pull requests should focus on the
  `{{project-name}}` codebase, its architecture, and its implementation.
- **Conduct:** be direct about code and considerate about people. Critique the
  change, not the contributor.
- **Moderation:** off-topic, abusive, or bad-faith content will be closed or
  removed.

Report conduct concerns to the maintainers{% if author_email != "" %} at
{{author_email}}{% else %}, or through GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature{% endif %}.
